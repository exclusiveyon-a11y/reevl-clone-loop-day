# B. 공유 루프 심층 조사

조회일 2026-10-24, GA4 읽기 전용 질의(사람 필터). 질의는 [analysis/ga_report.py](../analysis/ga_report.py)에 있다.

## 결론

"카톡 버튼 추가"가 아니다. **비교 결과를 카톡·카페에 붙이기 좋은 근거로 만들고, 공유를 계측한다.**

## 실측

### 1. 우리 공유 버튼은 계측상 0건

- 최근 30일 `share` 이벤트 0건, 공유 UTM(`utm_source=reevl_share`) 세션 0.
- 계측과 UTM은 단지 페이지의 작은 공유 아이콘에만 붙어 있다.
- 비교·임대/분양·스크리너 공유에는 이벤트도 UTM도 없다.

### 2. 그런데 비교 링크는 퍼지고 있고, 가장 질이 좋다

| 착지 | 세션(30일) | 참여율 | 평균 시간 | 세션당 페이지뷰 |
|---|---:|---:|---:|---:|
| 비교 공유 링크 | 65 | 89% | 132초 | 7.0 |
| 사이트 평균 | 8,753 | 71% | 95초 | 2.6 |
| 임대·분양·유형 | 3,918 | 68% | 79초 | 1.7 |

출처: 네이버 검색 22 (비교 주소가 색인됨) / 네이버 카페 21 / naver.com 14 / 직접 8.

### 3. 꾸준한 유입원은 네이버 카페 글

- 90일 동안 네이버 카페 한 곳의 글 3개가 반복 유입원이다.
- 카페 안 검색어로 들어온다: 오금삼성, 둔촌현대, 상아2차, 가락, 마천, 리모델링. 송파 리모델링 단지를 비교하는 글이다.
- 카페 글은 오래 검색에 걸려 계속 사람을 보낸다.

많이 퍼진 비교 (90일 세션): 매탄동 주공그린빌2 90 / 상계동 보람 51 / 오금동 삼성 47 / 마곡현대 vs 우장산 33.

### 4. 그 밖의 외부 경로 (90일)

페이스북 92 (아티클로), uibowl 64 (디자인 갤러리), 스레드 18.

### 5. 미리보기 카드

- 비교 링크만 전용 미리보기 이미지가 있다.
- 단지·임대 링크는 사이트 공통 이미지라, 카톡·카페에 붙이면 어느 단지인지 안 보인다.

### 6. 보이지 않는 것

GA4에 인앱 앱 구분 항목이 등록돼 있지 않아 카카오톡으로 들어온 사람을 따로 볼 수 없다.

## 해석

- 퍼지는 단위는 단지 하나가 아니라 **비교**다. 카페에서 "A vs B"를 이야기할 때 근거로 붙인다.
- 보이는 범위에서 공유처는 카톡보다 **네이버 카페**다. 카톡은 0이 아니라 안 보이는 것일 수 있다. 계측이 먼저다.

## 실행안

**B0 계측 수리** (약 1시간, 가장 먼저)
- 비교·임대/분양 공유와 짧은 링크에 `share` 이벤트와 UTM을 붙인다. 공유 대상은 `utm_content=compare|housing|complex`로 구분한다.
- 정식 주소(canonical)는 깨끗한 주소 그대로라 색인 영향이 없다.
- GA4 관리 화면에서 맞춤 측정기준(인앱 앱·공유 방식·공유 대상)을 등록한다.

**B1 카카오톡 공유를 데이터 카드로**
- 카카오 기본 템플릿(피드)에 단지명, 최근 실거래, ㎡당 가격, "1년 전망 상위 N%"를 항목으로 넣는다.
- 버튼 2개: 비교 보기 / 내 단지 넣어 비교.
- 이미지를 새로 만들지 않는다(서버 부하 0). 공유 기능 스크립트는 버튼을 누를 때만 불러온다.
- 카카오 JS 키는 지도에 쓰는 것을 재사용한다. 콘솔에서 JS SDK 도메인 등록을 확인한다.
- 무료 한도 하루 30,000건. 유료 사용 설정을 켜지 않으면 넘어도 실패할 뿐 과금되지 않는다.
- 선택: 전송 성공 웹훅(`serverCallbackArgs`)으로 실제 보낸 수를 센다.

**B2 카페에 붙이기**
- 단지별 최근 실거래·평형·전망 순위 3줄 요약과 짧은 링크를 한 번에 복사한다.
- 네이버 공유 버튼은 공식 문서를 확인하지 못해 보류한다.

**B3 공유 위치**
- 비교 결과 바로 아래 큰 공유 버튼 (지금은 흐린 작은 아이콘).
- 단지 페이지: "근처 단지와 비교해서 보내기" — 공유 단위를 비교로 유도.
- 임대·분양 페이지: "가족에게 공고 보내기" (접수 D-day 포함).

**보류: 단지별 미리보기 이미지**
크롤러가 4.5만 장을 긁으면 서버 CPU 사고가 날 수 있다. 카카오 카드의 텍스트 항목으로 대신한다.

| 지표 | 기준 | 목표 |
|---|---:|---:|
| `share` 이벤트 | 0 | 주 50+ |

| 공유 착지 참여율 | 89% | 85% 이상 유지 |
| 공유 착지 세션당 페이지뷰 | 7.0 | 5 이상 유지 |
| 공유 1건당 유입 세션 | 측정 전 | 기준값 확보 |

가치는 방문의 질, 네이버 외 채널, 카페 글이라는 외부 링크다.
