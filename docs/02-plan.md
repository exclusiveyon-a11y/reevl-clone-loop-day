# 실행 계획

해커톤 현장 2시간에 만들고 내보낸 뒤, 7일 동안 측정한다.
모든 기능은 리블 본체 저장소의 별도 브랜치에서 만들고, 스위치가 꺼진 상태로 배포한 뒤 켠다.

## A. 공고 D-day 루프

**왜**: 임대·분양 착지가 4주 만에 2,210으로 가장 빨리 컸고, 가장 얕다(세션당 1.72 페이지).
이 사람들은 접수 시작·마감·발표라는 **다시 올 날짜**가 정해져 있다.

1. 임대·분양 페이지에 "청약·임대 D-day 매일 받기 → 텔레그램" 버튼. 채널은 이미 청약 D-day를 매일 보낸다(새 기능 없음).
2. 2단계: 공고별 이메일 알림. 기존 메일 발송(Resend)과 알림 발송 경로를 재사용한다. 무료 한도(하루 100통) 안에서 상한을 건다.

측정: 버튼 클릭(전환), `utm_source=telegram` 재유입, `return_visit`.

## C. 런칭 스파이크 + 외부 링크

배포가 필요 없다. 각 링크에 UTM을 단다.

| 채널 | 내용 | 비고 |
|---|---|---|
| 긱뉴스 Show GN | 개인이 만든 전국 아파트 실거래·AI 전망 서비스, ChatGPT·Claude 플러그인 | 개발자 독자. 본인 계정 |
| 디스콰이엇 | 메이커 런칭 글 | 본인 계정 |
| 개발 블로그 | 이미 써 둔 제작기 재게시 | 외부 링크 |
| 플러그인 목록 | ChatGPT·Claude 플러그인 소개 페이지 | 외부 링크 |

커뮤니티 규칙을 먼저 읽고, 홍보 금지인 곳에는 올리지 않는다.

## D. 깊이

임대·유형 페이지 본문 아래에 다음 단계를 붙인다: 같은 지역 다른 공고, 접수 D-day, 근처 단지.
주소·제목·설명·정식 주소는 바꾸지 않는다. 서버 HTML 본문은 줄이지 않는다.

측정: 해당 착지의 세션당 페이지뷰, 평균 세션 시간.
