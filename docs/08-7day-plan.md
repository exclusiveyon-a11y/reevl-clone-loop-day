## 지키는 것

- 모든 댓글에 짧은 관계 공개. 공개 없이 일반 사용자처럼 쓰지 않는다.
- 커뮤니티 공지에서 홍보·링크가 금지면 그 채널은 링크 없는 답변만 하거나 뺀다. 삭제·경고가 한 번이라도 나오면 그 채널은 즉시 중지.
- 자동 게시는 허용 목록에 있는 채널만, 하루 3건, `GTM_AUTOPUBLISH=1`일 때만.
- Claude 예산 하루 $8 · 총 $98(크레딧 11/7 만료), 검색 API 하루 상한(네이버 300 · 다음 500 · 유튜브 3,000단위). 유료 광고 0원.
- 리블 본체 배포는 승인 후에만 한다.

## 결정이 필요한 것

1. `ANTHROPIC_API_KEY`를 리블 `.env`에 넣기, 콘솔에서 월 지출 한도 설정
2. 하루 3회 예약 실행(맥 launchd) 생성
3. 리블 `/c/키` 리다이렉트가 UTM을 넘기도록 1줄 수정 + 배포
4. 긱뉴스·디스콰이엇 런칭 글을 누구 계정으로 올릴지
5. 허용 채널 목록 (커뮤니티 공지 확인 후)
