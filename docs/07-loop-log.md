# 루프 개선 기록

평가 기준 "중간 결과를 바탕으로 루프가 개선됐는가"를 위해, 돌릴 때마다 무엇을 보고 무엇을 바꿨는지 적는다. 7일 동안 매일 이어 쓴다.

## D0 · 2026-10-24 (해커톤 당일)

| 회차 | 본 것 (실측) | 바꾼 것 |
|---|---|---|
| 1 | 다음 카페 실행: 사람 대기열 42건 대부분이 무관한 글(그림책 카페가 '대치초' 허브에 걸림) | 내용 점수(적합도+데이터+최신성) 6 미만은 사람에게도 넘기지 않음 |
| 2 | 대기열에 중개 매물 광고 글이 단지 이름으로 걸림 | 질문 신호(?·고민·어디·비교·추천…)가 없거나 광고 신호(급매·매물·중개사무소…)가 있으면 제외. 같은 카페는 한 번 실행에 한 글만 |
| 3 | 네이버 검색 401 — 리블 키는 데이터랩용 | NAVER API HUB 키로 전환(호스트·헤더가 다름), 하루 300회 상한 |
| 4 | 리블 공개 API 한 건 시간 초과가 실행 전체를 끊음 | 건별 예외 처리, 6시간 캐시·1회 재시도·호출 간격(라이브 서버 보호) |
| 5 | 사용자 피드백: "댓글이 너무 길고 링크도 길다" | 2~3줄, 링크 하나, 비교는 리블 단축 링크(/c/키, 약 30자) |
| 6 | 사용자 피드백: "글쓴이 궁금증을 잡아 솔루션처럼" | 고민 유형(비교·시세·학군·전세·재건축·출퇴근) 감지 → 데이터로 먼저 답 → 리블 기능 한 줄. 고점을 물으면 고점 대비 위치로 답 |
| 7 | 네이버 카페만으로는 좁음 | 다음 웹검색 `site:`로 국내 커뮤니티 10곳 + 유튜브 댓글 + 뽐뿌 RSS 추가. 채널별 말투 |
| 8 | 부동산스터디 운영가이드 확인: 노골적 광고 금지·링크 공유글 삭제·도배 강퇴 | 자동 게시 기본 중지(`GTM_AUTOPUBLISH`), 허용 목록 없이는 0건 |
| 9 | 규칙 매칭 오류: '증여의 시대'의 '시대'→전남 단지, '목동진도2차'→금천구 독산동 | Claude 연결(Haiku 판정·Sonnet 추출·작성·Haiku/Opus 심사). 추출한 구·동으로 매칭하고, 확정 못 하면 규칙 매칭으로 돌아가지 않고 제외 |
| 10 | 추출 표기('목동진도2차')와 리블 이름('진도2'·'목동우성2', 신정동)이 달라 0건 | 핵심 이름 정규화(동네 접두·'차'·'아파트' 제거), 같은 구 안 재탐색, 이름 앞 동네를 단서로 동명 단지 구분 |
| 11 | Sonnet 5.5가 강제 tool_choice·temperature를 거부(400), triage가 매칭 전에 '매칭 없음'으로 감점 | 자동 tool 호출+JSON 파싱, temperature 제거, triage는 질문·적절성만 판정 |
| 12 | 첫 실게시 검토에서 사용자: "너무 길고 애매", "괄호 제거" | 형식 확정: 두 줄 · 괄호·날짜 없음 · 글쓴이가 말한 평형 기준 · 공개는 문장 안("제가 운영하는 리블에 … 정리해 뒀어요"). 부동산스터디 1건 게시·화면 확인(사용자 승인) |

결과: 회차 1 → 8에서 사람 확인 후보의 잡음이 42건(대부분 무관) → 12건(질문 글·리블 페이지 매칭·점수 통과)으로 줄었다.

- D7: 최종 판독(GA 처리 지연 때문에 D9에 확정치 갱신)
