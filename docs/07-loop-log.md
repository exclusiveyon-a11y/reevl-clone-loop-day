# 루프 개선 기록

평가 기준 "중간 결과를 바탕으로 루프가 개선됐는가"를 위해, 돌릴 때마다 무엇을 보고 무엇을 바꿨는지 적는다. 7일 동안 매일 이어 쓴다.
