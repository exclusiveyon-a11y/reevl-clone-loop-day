# Claude 연동 설계와 예산 ($100 크레딧)

상태: **D0(10-24) 구현·실가동.** 판정 Haiku 5.5 · 추출·작성 Sonnet 5.5 · 재심 Opus 5.5. 아래 단가는 공식 요금표(platform.claude.com/docs/en/about-claude/pricing, 2026-10-24 조회)에서 가져왔다.

## 왜 붙이나: 사람 검수를 0에 가깝게

지금 규칙 기반 루프는 365건 중 12건을 사람 확인으로 넘긴다. 남은 사람 일은 세 가지다. 정말 답할 만한 질문인가, 그 카페 규칙상 괜찮은가, 초안이 틀리거나 과장되지 않았나. 셋을 Claude 판정으로 바꾸고, 사람은 확신이 낮은 예외와 하루 몇 건 표본 감사만 본다.

| 단계 | 모델 | 하는 일 | 사람이 보는 경우 |
|---|---|---|---|
| 1. 질문 판정 | Haiku 5.5 | 실제 질문인지, 리블 페이지가 답이 되는지, 댓글이 적절한지(광고·뉴스·정치 제외) + 고민 유형·단지·지역 구조화 추출 | 확신 낮음 |
| 2. 규칙 판정 | Sonnet 5.5 | 커뮤니티 공지를 읽고 홍보·링크 허용 여부를 근거 문장과 함께 판정 → `rules.json` | 근거 문장이 없을 때 |
| 3. 맞춤 답변 | Sonnet 5.5 | 넘겨준 실거래 데이터만으로 그 질문에 맞는 2~3줄 답, 채널 말투, 공개 문구 필수 | — |
| 4. 발행 전 심사 | Haiku 5.5 + 코드 | 코드: 숫자가 데이터와 일치하는지 대조. Claude: 투자 권유·단정·배정 확정·공개 누락·지어낸 사실 판정 | 둘 중 하나라도 실패 |
| 5. 게시 후 관리 | Haiku 5.5 | 우리 댓글의 반응(질문·반박·삭제) 분류, 후속 답 초안 | 반박·신고 |

Claude가 숫자를 만들지 않게 한다. 숫자는 리블 공개 API에서 코드가 가져오고, Claude는 그 JSON 안에서만 쓴다.

7일 루프 전체 약 $3. 검색어·채널을 10배로 늘려도 $100 안에 든다. 시스템 지시문(말투 가이드·규칙·예시)은 프롬프트 캐싱으로 입력 단가를 더 낮춘다.

## 쓰는 도구

- **Messages API**: 실시간 루프(1·3·4단계)에 쓴다. 구조화 출력(JSON)으로 판정 이유를 남긴다.
- **Batch API**: 밤사이 하루치 후보 일괄 판정(50% 할인).
- **Agent SDK**: 찾기·매칭·초안·심사를 도구로 묶어 한 에이전트가 루프를 돈다. 결과는 지금 큐·관리자 콘솔에 그대로 쌓인다.
- **Managed Agents**: 맥이 꺼져 있어도 24시간 찾기·초안·알림을 돌리는 후보(요금 확인 후 결정). 게시는 계속 로컬 Aside 또는 사람이 한다.
- **Playground**: 말투·심사 프롬프트를 실제 후보로 조정하는 곳.

## 예산 안전장치

- 코드: `data/claude_spend.json`에 실제 사용 토큰 × 위 단가로 누적. **하루 $8, 총 $98**(크레딧 $100, 11/7 만료)에서 멈추고 규칙 기반으로 돌아간다.
- 콘솔: 워크스페이스 월 지출 한도를 크레딧 이하로 설정한다.
- 키는 리블 본체 `.env`의 `ANTHROPIC_API_KEY`로만 읽는다. 이 저장소에는 없다.
