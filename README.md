# 리블 GTM 해커톤

[리블](https://reevl.co.kr)은 전국 아파트 약 4.5만 단지의 실거래·입지·AI 전망을 무료로 보여주는 서비스다.
이 저장소는 GTM 해커톤(현장 2시간 실행 + 7일 측정)의 작업 공간이다.
리블 본체 코드는 별도 비공개 저장소에 있다. 여기에는 계획, 기준값, 측정 스크립트, 결과만 둔다.

## 목표

7일 동안 **네이버 밖 실사용자 유입**과 **재방문·전환**을 숫자로 올린다.
네이버 검색 유입은 이미 혼자 크고 있으므로, 우리가 한 일로 생긴 **증분만** 성과로 센다.

| 지표 | 기준값 (최근 7일, 10/17~23) | 7일 목표 |
|---|---|---|
| 네이버 외 외부 유입 | 주 66명 | 주 500명+ |
| 재방문율 | 3.8% | 6% |
| 전환율 (공유·알림·저장) | 약 0.1% | 임대·분양 착지 1% |
| 평균 세션 시간 | 87.5초 | 95초 |
| 세션당 페이지뷰 | 2.28 | 2.5 |
| 공유 이벤트 | 0건 (30일) | 주 50건+ |
| 공유로 들어온 세션 | 0 (UTM 기준, 30일) | 주 100세션 |

숫자의 출처와 정의는 [docs/01-baseline.md](docs/01-baseline.md), 측정 방법은 [docs/04-measurement.md](docs/04-measurement.md)에 있다.

## 진단 세 줄

1. 유입은 네이버가 키우고 있다(7일 +62%). 늘어난 곳은 임대주택·유형·분양예정 페이지다.
2. 늘어난 사람이 얕게 보고 돌아오지 않는다. 세션당 페이지뷰 2.64→2.28, 재방문 3.8%, 저장 전환 사실상 0이다(세션 시간은 88초 보합).
3. 가장 질 좋은 유입은 공유된 **비교 링크**다(참여율 89%, 132초, 7.0 페이지). 그런데 공유 계측은 0건이다.

## 지킬 것

- 기존 유입을 깎지 않는다. 유입이 있는 페이지의 주소·제목·설명·정식 주소(canonical)는 바꾸지 않는다.
- 배포는 한 번, 승인 후에만 한다. 새 기능은 스위치로 끌 수 있게 만든다.
- 네이버 템플릿 유입이 전주 대비 15% 넘게 빠지면 해당 실험부터 끈다.
- 돈이 드는 설정은 켜지 않는다(카카오 유료 사용, 이메일 무료 한도 초과 등).
- 커뮤니티에 우리 계정으로 홍보 글을 도배하지 않는다. 사용자가 공유하기 쉽게 만드는 데 집중한다.
- 이 저장소에 키·토큰·원본 분석 파일·개인 식별 정보를 올리지 않는다.
